OpenSSL Revocation Check

Use the following OpenSSL command to verify that an end-user certificate (and the intermediate) is not revoked: 

openssl verify -crl_check_all -CAfile root.pem -untrusted intermediate.pem -CRLfile crl-bundle.pem certificate.pem

Or alternatively, you can concatenate all the necessary files into one and run the command like this: 

openssl verify -crl_check_all -CAfile full.pem certificate.pem

With the following files:

  • root.pem is the root certificate.
  • intermediate.pem is the intermediate certificate.
  • crl-bundle.pem is the CRL bundle for the root and intermediate certificates.
  • full.pem is the concatenation of all of them.
  • certificate.pem is the target fcertificate.
